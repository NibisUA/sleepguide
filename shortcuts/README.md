# iOS Shortcuts для SleepGuide

Цей файл пояснює, як налаштувати на iPhone автоматизації, які самі відправляють дані в SleepGuide:

1. **Початок сну** — коли вмикається фокус «Сон» (Sleep Focus).
2. **Кінець сну** — коли фокус «Сон» вимикається.
3. **Екранний час** — щоденне запитання вранці про вчорашній день.

Нічого не потрібно встановлювати: усе робиться в стандартному застосунку **Команди (Shortcuts)**.
Назви дій нижче англійською (як в оригінальному інтерфейсі); якщо в тебе iPhone українською,
шукай дію за англійською назвою у пошуку, а підказки в дужках допоможуть її впізнати.

> Усі адреси нижче для домену `https://sleepmaxxing.pp.ua`. Якщо домен інший, заміни його.

## 0. Створи токен

1. Відкрий SleepGuide у Telegram → **Налаштування** → розділ **Інтеграції (iOS Shortcuts)**.
2. Введи назву (наприклад, `iPhone`) і натисни **Створити**.
3. Натисни **Копіювати** і **збережи токен**: він показується лише один раз. Токен має вигляд
   `sg_...` і діє як пароль: нікому його не показуй і не вставляй у чати.
4. Якщо токен загубився або потрапив не в ті руки, відклич його в тому ж розділі (**Відкликати**)
   і створи новий. Автоматизації зі старим токеном одразу перестануть працювати.

Токен дозволяє лише три дії: початок сну, кінець сну і запис екранного часу. Прочитати твої дані
чи керувати токенами з ним неможливо.

## 1. Команда «Sleep Start» (початок сну)

У застосунку **Команди** → вкладка **Shortcuts** → **+** (нова команда). Назви її `Sleep Start`.

Додай одну дію **Get Contents of URL** («Отримати вміст URL-адреси») і розгорни її параметри (**Show More**):

| Параметр | Значення |
| --- | --- |
| URL | `https://sleepmaxxing.pp.ua/api/v1/sleep/start` |
| Method | `POST` |
| Headers | `Authorization` = `Bearer sg_...` (твій токен після слова `Bearer` і пробілу) |
| Request Body | не потрібне (залиш порожнім) |

Натисни ▶ для перевірки: у відповіді має бути JSON із `"started_at"`. У застосунку SleepGuide на головній
з'явиться сон, що триває. Повторний запуск нічого не зламає: якщо сон уже триває, повертається той самий.

## 2. Команда «Sleep Stop» (кінець сну)

Створи другу команду `Sleep Stop`, так само з дією **Get Contents of URL**:

| Параметр | Значення |
| --- | --- |
| URL | `https://sleepmaxxing.pp.ua/api/v1/sleep/stop` |
| Method | `POST` |
| Headers | `Authorization` = `Bearer sg_...` |
| Request Body | не потрібне |

Якщо сон триває понад 14 годин, сервер відповість помилкою `wake_time_required`: час пробудження
тоді потрібно вказати в застосунку (кнопка «Я прокинувся» або редагування сну).

## 3. Автоматизація від фокусу «Сон»

1. У **Команди** → вкладка **Automation** → **+** → **Personal Automation** (особиста автоматизація).
2. Обери тригер **Focus** («Фокусування») → **Sleep** («Сон») → постав позначку **When Turning On**
   («Коли вмикається») → **Next**.
3. Додай дію **Run Shortcut** («Запустити команду») → вибери `Sleep Start` → **Next**.
4. Вимкни **Ask Before Running** («Запитувати перед запуском») і, якщо є, **Notify When Run**.
   Підтверди **Don't Ask** → **Done**.
5. Повтори пункти 1–4 ще раз: тригер **Focus → Sleep → When Turning Off** («Коли вимикається»),
   дія **Run Shortcut** → `Sleep Stop`.

Тепер сон починається і закінчується разом із твоїм фокусом «Сон» (за розкладом сну в Здоров'ї або вручну
з Центру керування).

## 4. Екранний час за вчора

iOS не дозволяє автоматизаціям читати «Екранний час», тому цю команду доведеться підтверджувати
числами вручну: це 10 секунд вранці. Подивися вчорашні значення в **Параметри → Екранний час** і введи їх.

Створи команду `Screen Time` з такими діями (по порядку):

1. **Ask for Input** («Запитати введення»): тип **Number**, запитання `Скільки годин на телефоні вчора?`
   → результат назви `Hours`.
2. **Ask for Input**: тип **Number**, запитання `Скільки хвилин (додатково до годин)?` → `Minutes`.
3. **Ask for Input**: тип **Number**, запитання `Скільки хвилин на телефоні за 2 години перед сном? (0, якщо не знаєш)`
   → `Bed`.
4. **Calculate** («Обчислити»): `Hours` × `60` → потім додай `Minutes`. Результат назви `Total`.
5. **Adjust Date** («Змінити дату»): **Current Date** мінус **1 day** → результат `Yesterday`.
6. **Format Date** («Форматувати дату»): `Yesterday`, формат **Custom**, шаблон `yyyy-MM-dd` → результат `Day`.
7. **Get Contents of URL**:

| Параметр | Значення |
| --- | --- |
| URL | `https://sleepmaxxing.pp.ua/api/v1/screen-time/` і одразу після неї змінна `Day` |
| Method | `PUT` |
| Headers | `Authorization` = `Bearer sg_...` |
| Request Body | **JSON** з двома полями типу **Number**: `total_minutes` = `Total`, `before_bed_minutes` = `Bed` |

Правила сервера: `total_minutes` від 0 до 1440; `before_bed_minutes` від 0 до 120 і не більше за
`total_minutes`; день не пізніше сьогодні й не раніше ніж рік тому. Повторне відправлення того самого дня
просто замінює запис.

Щоб команда запускалась сама вранці: **Automation** → **+** → **Time of Day** (наприклад, 09:00, щодня) →
**Run Shortcut** → `Screen Time` → залиш **Ask Before Running** увімкненим, бо команда задає питання.

## Помилки

| Відповідь сервера | Що це означає |
| --- | --- |
| `401 invalid_token` | токен неправильний, відкликаний або в заголовку немає слова `Bearer ` |
| `422 invalid_screen_time` | час перед сном більший за 2 години або за загальний час |
| `422 invalid_date` | день у майбутньому або старший за рік; перевір формат `yyyy-MM-dd` |
| `429 rate_limited` | забагато запитів або забагато невдалих спроб; зачекай кілька хвилин |
| `409 wake_time_required` | сон триває понад 14 годин; вкажи час пробудження в застосунку |

Токен відправляється в кожному запиті в заголовку `Authorization`, тому не публікуй скриншоти команд
разом із ним.

## Для розробників: запити вручну

```bash
curl -X POST https://sleepmaxxing.pp.ua/api/v1/sleep/start -H "Authorization: Bearer sg_..."
curl -X POST https://sleepmaxxing.pp.ua/api/v1/sleep/stop  -H "Authorization: Bearer sg_..."
curl -X PUT  https://sleepmaxxing.pp.ua/api/v1/screen-time/2026-10-04 \
  -H "Authorization: Bearer sg_..." -H "Content-Type: application/json" \
  -d '{"total_minutes": 318, "before_bed_minutes": 34}'
```
