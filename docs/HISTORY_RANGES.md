# Історія: 7 / 30 / 90 днів і весь період

Розширення після рекордів і серій, 12.10.2026.

## Використання

У вкладці **Історія** обери 7, 30, 90 днів або **Весь період**. Вибір спільний
для сну, тренувань, стресу й екранного часу. Фактичні дати показані з роком;
підсумки охоплюють весь вибраний діапазон.

«Весь період» починається з найдавнішого завершеного сну/тренування або запису
стресу/екранного часу цього акаунта і закінчується сьогодні за поясом профілю.
Обмеження одним роком немає. Відкриті таймери й майбутні дати не включені.
У порожньому акаунті показується сьогодні та повідомлення про відсутність даних.

Списки впорядковані від новіших до старіших, по **30 за сторінку**. Кнопка
**Показати ще** окрема для кожної категорії. Старі ліміти 50/100/200/500 не
обрізають нові списки. Сон також має список за вибраний період. Після помилки
наступної сторінки вже видимі записи залишаються, є повтор. Редагування,
видалення та результати вправ зберігають попередні можливості.

Для екранного часу залишається правило ручного внесення/редагування за останній
рік: старіші збережені дані можна читати й видаляти. Кнопка їх зміни вимкнена
з поясненням. Історія не видаляє записи після року.

## Графіки й числа

- До 90 днів: одна точка на календарний день.
- Довші періоди: блоки по ceil(кількість днів / 90), максимум 90 точок.
  Період і масштаб підписані. Графік можна гортати горизонтально; початково
  видно останні дати. Його висота не зростає з кількістю точок.
- Сон: середня сумарна тривалість основного сну за записані дні в блоці.
  Денний сон залишається в списках, у тривалість основного сну/Score не входить.
- Score: середнє денних оцінок із даними; пропуски не з’єднуються лінією.
- Тренування: сумарні хвилини завершених тренувань у блоці.
- Стрес: середнє всіх оцінок; максимум позначається рискою.
- Екран: середній час за записані дні; pre-bed — за дні, де його задано.
  Явний 0 враховується, відсутні значення не перетворюються на нулі.

Підсумки обчислюються з усіх вихідних значень, **не із середніх графічних блоків**
і не з першої сторінки. Сон усереднюється по днях з основним сном, стрес —
по оцінках, екран — по записаних днях. Усі тексти доступні uk/en.

Для Sleep Score читання тепер мають єдиний контекст 120 попередніх днів,
як /sleep/score/{date}. Виправлено розбіжність рідкісної історії: старий
/sleep/history використовував 90 днів або весь префікс вікна. Формула й ваги
компонентів не змінені; денний, річний і новий діапазонний перегляди узгоджені.

## API

Нові read-only ендпоінти під /api/v1 потребують JWT Mini App; Shortcuts не приймаються.

- GET /history?range=7d|30d|90d|all: узгоджений snapshot, дати, кількість днів,
  масштаб, чотири точні підсумки й до 90 комбінованих точок.
- GET /history/entries/{sleep|workout|stress|screen}?from=YYYY-MM-DD&to=YYYY-MM-DD:
  відповідна колекція та next_cursor. limit 1–100 (default 30), cursor необов’язковий.
  next_cursor = null означає кінець списку.

Cursor — opaque base64url із датою/часом/ID. Сортування: збережена local_date,
час та ID у спадному порядку. Рівні timestamps не гублять рядки; видалення
останнього запису попередньої сторінки не збиває продовження. Cursor не дає
доступу: кожний запит незалежно фільтрується за акаунтом. Некоректні дати,
cursor, limit повертають 422 у звичному форматі. Редагування часу між сторінками
може змінити позицію запису; оновлення застосунку заново читає сторінки.

Стрес/тренування агрегуються в SQL; Score обчислюється з рухомим контекстом
замість сканування всіх років для кожної ночі. Порожні календарні дні не
створюють необмежений JSON/DOM. Експорт залишається 1.1; нової міграції немає,
head = 0008. Річний heatmap та старі обмежені API для нього збережені.

## Перевірено

- **227 backend tests**, PostgreSQL 16: 450 днів, історія понад рік,
  усі сторінки 450 снів / 450 тренувань / 900 оцінок / 450 днів екрана,
  точні суми/середні, чужі акаунти, виключення future/open, timezone,
  порожній акаунт, рівні timestamps, видалення boundary-запису, validation,
  JWT/Shortcuts, узгодженість Score для рідкісної історії.
- **25 frontend tests**: перемикання 90/all, активні кнопки й масштаб,
  завантаження ще без зміни підсумків, збереження видимих рядків після помилки
  та повтор, розрив лінії на пропущених датах і попередні тести.
- ruff, typecheck, build і Alembic check. Локально Vite/Vitest запускалися
  з --configLoader runner, щоб працювати всередині sandbox. CI зберігає
  стандартні команди; віддалений GitHub Actions не запускався.
- Початковий JS 125.92 kB gzip, History 11.00 kB, CSS 5.41 kB.
- Браузер 375 × 812, локальна PostgreSQL: 90 днів і весь період
  19.07.2025–12.10.2026, групування до 6 днів, наступні 30 тренувань,
  без помилок console й горизонтального переповнення сторінки.
  Це синтетичні дані та перевірка ширини, не фізичний Telegram-клієнт.
