# CSV, Shortcuts, звук і тренування — 13.10.2026

## Імпорт та експорт

Історія → «Імпорт і експорт CSV», або той самий блок у Налаштуваннях.
Окремі CSV для сну, тренувань, стресу та екранного часу. JSON-експорт усіх
даних і налаштувань також збережено. CSV тренувань містить час/тип/інтенсивність;
вправи та підходи є в повному JSON-експорті, імпорт підходів через CSV не реалізований.

Сон — формат як у таблиці користувача:

```csv
Дата,Час коли заснув,Час коли прокинувся
26.09.2026,23:30,07:30
27.09.2026,01:15,09:00
```

Дата — день пробудження. Перший рядок означає ніч 25→26 вересня.
Години `0:00` і `00:00` підтримуються. Тривалість обчислюється з часів;
колонку «Кількість годин сну» можна залишити, її значення не використовується.
Ніч через північ визначається автоматично. Короткий сон класифікується як
дрімота за чинними правилами. Імпорт використовує часовий пояс профілю.

Також приймаються `date,bedtime,wake_time`, `sleep_start`, дати `YYYY-MM-DD`,
`DD.MM.YYYY`, `DD/MM/YYYY`, CSV UTF-8 із BOM / без BOM, кома / крапка з комою / табуляція.
Файл до 1 МБ, пакет до 2000 рядків. Спочатку попередній перегляд з помилками,
дублікатами та розрахованою тривалістю; потім окрема кнопка імпорту.
Будь-яка помилка зупиняє весь пакет. Дублікати пропускаються, перетини
та різні екранні записи на ту саму дату не перезаписуються.
Паралельні імпорти й звичайні записи серіалізуються за власником.
Після імпорту історія перемикається на весь період.

Експорт містить усі завершені записи, видимі локальні дати/часи та точні
`started_at,ended_at` / `logged_at` з UTC-зсувом. Це зберігає секунди,
мікросекунди та відмінність між повтореними годинами під час зміни годинника.
Щоб редагувати сон або тренування у таблиці, видали `started_at,ended_at`
і залиш видимі колонки дати/часу. Суперечливі колонки викликають помилку,
редагування не ігнорується. Для стресу редагуй `logged_at` або видали цю колонку.
Неоднозначні / неіснуючі локальні DST-часи потрібно задавати точними timestamp.

Шаблони інших типів:

```csv
date,start,end,type,intensity
2026-09-26,18:00,19:00,gym,moderate
```

Дата тренування в CSV — день завершення, у звичайній історії тренування
групуються за днем початку. Типи: `gym,home,running,football,walking,other`.
Інтенсивність: `easy,moderate,hard,very_hard`. Максимум 6 годин, як у звичайній формі.

```csv
date,time,level,category
2026-09-26,18:00,3,work
```

Стрес 1–5. Категорія необов’язкова: `university,work,relationships,money,sleep,training,personal,other`.

```csv
date,total_minutes,before_bed_minutes
2026-09-26,240,30
```

Екран: всього 0–1440 хв; перед сном 0–120 хв і не більше загального часу.
CSV дозволяє перенести стару історію; майбутні дати не приймаються.

## Shortcuts на iPhone

У Налаштуваннях додано інструкцію для трьох команд з копіюванням URL:
«Ліг спати», «Прокинувся», ручний запис екранного часу.
Сон працює як таймер, не визначає фактичне засинання і не імпортує Apple Health.

1. Створи в SleepGuide токен для iPhone, скопіюй повне значення один раз.
2. Shortcuts / «Команди» → + → команда «Ліг спати».
3. Дія URL: `https://sleepmaxxing.pp.ua/api/v1/sleep/start`.
4. Get Contents of URL / «Отримати вміст URL»: метод POST,
   Headers `Authorization: Bearer <повний sg_токен>`, JSON без полів `{}`.
5. Повтори для «Прокинувся» з `/sleep/stop`.
6. Запусти вручну: спочатку start, згодом stop. Час — момент запуску.
   Автоматизацію додавай після ручної перевірки: розклад / Focus не є детектором сну.

Екранний час: PUT `/api/v1/screen-time/YYYY-MM-DD`, JSON із числовими
`total_minutes,before_bed_minutes`. Автоматичного читання iOS Screen Time немає.
Токен SleepGuide не є токеном бота і не дає доступ до експорту, видалення чи імпорту.
401 — токен недійсний, 403 — дія недоступна, no_open_session — сон не запущено,
wake_time_required — потрібен явний час пробудження у SleepGuide.
Офіційні дії Shortcuts: [Apple](https://support.apple.com/guide/shortcuts/apd58d46713f/ios).

## Звук

Налаштування → Нагадування → «Звук нагадувань». За замовчуванням увімкнено
для ранкових та вечірніх повідомлень; вимкнення надсилає обидва без звуку.
Раніше ранковий код явно задавав `disable_notification=True`.
Міграція **0010** додає `users.reminder_sound_on`, налаштування включене в JSON-експорт.
Це не будильник: звук також залежить від налаштувань Telegram, чату та ОС.
Параметр доставки: [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage).
Жодне тестове повідомлення реальному користувачу не надсилалось.

## Тренування та рекорди

Вправи/підходи можна додавати під час активного таймера. Після ручного створення
тренування одразу відкривається журнал підходів. Одна форма може атомарно
зберегти 1–20 однакових силових підходів; різні ваги редагуються окремо.
Показано номери підходів, їх кількість та сумарний обсяг вправи в тренуванні.
Власна вага позначена словами, а не як підйом 0 кг.

Блок «Прогрес у вправах»: пошук, найважчий робочий підхід з повтореннями,
вибір ваги для рекорду повторень. Для кардіо — найдовша дистанція та часи
на кожній однаковій дистанції. З картки можна відкрити тренування-джерело.
Обсяг одного підходу й загальний максимум повторень перенесено в додаткові
показники; обсяг має одиницю кг × повторення, це не 1RM.
Рекорди враховують тільки завершені тренування. Видалення/редагування
перераховує рекорди. Скорочення тренування нижче часу вже записаного
кардіо відхиляється, зокрема при завершенні активного таймера.
