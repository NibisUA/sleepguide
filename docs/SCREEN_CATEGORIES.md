# Категорії екранного часу

Міграція **0011** додає необов’язкові поля `social_minutes`,
`entertainment_minutes`, `games_minutes` до денного запису.
Соцмережі / розваги / ігри показуються синім / блакитним / помаранчевим
у формі, на головній картці, у списку історії та підсумку дня.

Загальний час залишається основним значенням. Категорії — його частини,
їхня сума не може перевищувати загальний час. Перед сном — окремий зріз
цього самого часу, а не четверта категорія, тож він не додається до суми.
Sleep Score та його ваги не змінені.

Порожнє поле / `null` означає невідомо; явний `0` означає відсутність використання.
Коли заповнені всі три категорії, залишок показано як «Інше»;
коли хоча б одна невідома — як «Не розподілено». «Інше» обчислюється,
не вводиться повторно і не зберігається як окремий дубль загального часу.

Існуючі записи міграція залишає без категорій. Старий Shortcut, який
надсилає лише загальний час, зберігає вже введені категорії. Щоб очистити
категорію, потрібно передати відповідне поле зі значенням `null`.
Якщо новий загальний час менший за збережену суму категорій, API відхиляє
оновлення з `invalid_screen_categories`, не видаляючи попередні значення.

## API / CSV / JSON

PUT `/api/v1/screen-time/YYYY-MM-DD`:

```json
{
  "total_minutes": 542,
  "before_bed_minutes": 30,
  "social_minutes": 326,
  "entertainment_minutes": 73,
  "games_minutes": 53
}
```

Поля категорій приймають цілі хвилини 0–1440 або null, дробові числа й bool
відхиляються. Обмеження суми перевіряється також у PostgreSQL.

CSV може містити ці необов’язкові колонки:

```csv
date,total_minutes,before_bed_minutes,social_minutes,entertainment_minutes,games_minutes
2026-09-26,542,30,326,73,53
2026-09-27,10,,0,,
```

Категорії видно у попередньому перегляді імпорту. Експорт CSV та повний
JSON-експорт включають їх; JSON schema 1.2 збережена з сумісними додатковими
полями. Старі CSV без категорій приймаються; повторний імпорт такого CSV
не стирає вже збережені категорії. Новий CSV з іншою розбивкою на вже
наявну дату показує конфлікт і пропонує редагувати запис, не перезаписуючи його.

## OCR

Імпорт скриншота розпізнає підписи Social / Entertainment / Games та
Соцмережі / Соціальні мережі / Розваги / Ігри. Використовуються слова з
координатами, щоб зіставляти значення під трьома колонками iOS-віджета,
а не брати значення осей графіка як категорії. Неоднозначні результати
залишаються порожніми; до збереження користувач перевіряє всі значення.

У вікні OCR є окремий перемикач «Також перенести розпізнані категорії».
Загальний час, менший за їхню суму, не можна вибрати з цим перемикачем.
Скриншот обробляється локально, зображення на сервер не завантажується.
Годинний графік не відновлюється зі стовпчиків: точних погодинних чисел немає.

На наданому прикладі локальний Tesseract із англійською моделлю розпізнав
542 хв загалом, 326 соцмереж, 73 розваг, 53 ігор. Залишок — 90 хв.
Виправлена типова помилка тонкого шрифту iOS «Th 13m» замість «1h 13m»;
підміна виконується тільки у відповідному числовому контексті категорії.
Реальний браузер/iPhone залишається окремою ручною перевіркою.

## Оновлення

Категорії додані до тієї самої гілки / PR #2, що й CSV та тренування.
Перед production потрібна резервна копія та міграція head0011.
0010→0011 зберігає попередні записи; downgrade видаляє тільки нові категорії,
тому це не спосіб зберегти їх після відкоту.
